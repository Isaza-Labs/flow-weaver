# Support

Use the channel that matches the request:

- **Setup and usage:** start with the [quick start](./QUICK_START_GUIDE.md) and the [documentation index](./docs/README.md).
- **Reproducible product defect:** open a bug report using the repository issue template. Include version or commit, deployment mode, and the minimal steps that reproduce it.
- **Feature or documentation proposal:** open a feature request, or a discussion where discussions are enabled.
- **Security vulnerability, exposed secret or active incident:** follow [SECURITY.md](./SECURITY.md). Never use a public issue, pull request or discussion for this.
- **Licensing, trademark or commercial question:** write to the address in the table below. Do not use a public issue for confidential terms.

## Contact routes

Each address is a monitored shared mailbox, not a personal one, so a request does not wait on one person being available. FlowWeaver, Nashira and Netora share these routes — name the product in the subject line.

## What support is, and is not

Answers here are best effort by the maintainers. No public support service-level agreement is in force unless it is established in a separate written agreement. Response targets for security reports are stated in [SECURITY.md](./SECURITY.md) and are operating targets, not contractual commitments.

Questions about a deployment you run yourself should include the deployment mode and the relevant configuration, with credentials, tokens, customer data and internal hostnames removed. Do not paste a `.env` file, a keyring path or a live token into any public channel.
