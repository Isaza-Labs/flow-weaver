# Maintainers

**Isaza Labs LLC** owns and stewards FlowWeaver and holds release authority. The project is published under the NetworkingDev brand; the contact addresses use that domain. See [governance](./GOVERNANCE.md) for decision-making roles.

Maintainers review contributions through GitHub pull requests. The repository does not currently publish a `CODEOWNERS` file or a named maintainer roster. An account's ability to review a pull request does not by itself grant release, licensing, or trademark authority.

## Responsibilities

- **Release authority:** Isaza Labs LLC approves releases and their license metadata.
- **Security coordination:** Use the private route in [SECURITY.md](./SECURITY.md) for vulnerability reports and coordinated disclosure.
- **Licensing decisions:** Changes to `LICENSE`, `NOTICE`, `legal/`, or license-scope notices require approval from Isaza Labs LLC.

Maintainership is granted by Isaza Labs LLC. Contribution does not confer ownership or trademark rights; see [governance](./GOVERNANCE.md) and the [trademark policy](./TRADEMARK.md).

For general support, conduct concerns, and legal or trademark questions, use the routes in [SUPPORT.md](./SUPPORT.md).
