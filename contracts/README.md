# Contracts

Versioned technical contracts shared by the FlowWeaver engine, UI and ecosystem.

Breaking changes require a new contract version or a documented migration path. A contract's schemas, canonicalization rules, examples and conformance material are kept together in one place: for `workflow.v1`, that place is the conformance kit in [`../conformance/`](../conformance/README.md), and [`workflow.v1/`](./workflow.v1/README.md) points to it.
