# Project governance

## Stewardship

Isaza Labs LLC owns and stewards the official FlowWeaver project, repositories, releases and product direction. Stewardship includes release authority, repository administration, security coordination, licensing decisions and protection of the FlowWeaver identity.

FlowWeaver is published and supported under the NetworkingDev brand, which is why the project's contact addresses use the `networkingdev.com` domain. Ownership, licensing and trademark rights sit with Isaza Labs LLC regardless of the brand a page or a mailbox carries. The routes are listed in [SUPPORT.md](./SUPPORT.md).

The current public maintainer and release-authority information is in [MAINTAINERS.md](./MAINTAINERS.md). This repository does not currently publish a `CODEOWNERS` file.

## Decision records

Material decisions affecting licensing, security posture, compatibility, public APIs, data handling or release channels require a dated decision record. Historical decisions are marked as superseded rather than silently rewritten.

## Maintainer roles

- Product and architecture.
- Backend and execution engine.
- Frontend and user experience.
- Integrations, specs, skills and workflows.
- QA and release evidence.
- Security and incident response.
- License and third-party compliance.

If named maintainers or `CODEOWNERS` rules are added, their accounts or teams must be verified in GitHub before rules that require their review are enabled.

## Changes

Changes use pull requests, review and required automated checks. Direct changes to the stable branch are reserved for documented emergencies. All commits require DCO sign-off unless generated by an approved automation identity with equivalent provenance controls.

## License continuity

Official first-party releases remain Apache-2.0 unless a later dated governance decision explicitly changes the policy. A policy change does not revoke rights already granted for earlier distributions.
